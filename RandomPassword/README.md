# 🔐 安全密码生成器

一个简洁易用的在线密码生成工具，帮助您快速生成高强度、安全的密码，适用于网站注册、账户保护、系统登录等场景。

## ✨ 功能特点

- **多种密码类型选择**
  - **随机**：生成高强度的随机密码，安全性最高。
  - **易记**：生成相对容易记忆的密码，兼顾安全与记忆性。
  - **PIN 码**：生成数字形式的 PIN 密码，适用于手机或应用程序锁定。

- **自定义密码长度**
  - 通过滑动条自由调整密码长度（支持 4 ~ 64 位）。

- **可选密码规则**
  - 包含数字
  - 包含符号
  - 大小写字母混合

- **实时生成**
  - 点击 **生成** 按钮即可立即获取新的密码。
  - 点击 **复制** 按钮一键复制密码到剪贴板。

## 🚀 使用方法

1. 打开网页。
2. 选择密码类型（随机、易记、PIN 码）。
3. 调整密码长度。
4. 按需选择是否包含数字、符号等。
5. 点击 **生成** 按钮获取密码。
6. 点击 **复制** 按钮，将密码复制到剪贴板。

## 🛡️ 安全建议

- 建议为不同网站和应用设置不同的密码。
- 建议定期更换密码以提高安全性。
- 密码生成后请妥善保存，防止泄露。

---

📌 **提示**：本工具仅在本地生成密码，不会将您的密码上传至服务器，确保您的隐私安全。
